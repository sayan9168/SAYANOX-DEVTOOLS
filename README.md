Code analysis · Security scanning · Project health · Optional local AI (Ollama)

## Features (v0.3.0)

| Feature | Description |
|---------|-------------|
| Interactive dashboard | Workspace overview |
| File analysis | Analyze current file |
| Security scan | Local security checks |
| Project health | Diagnostics & health signals |
| Quick Fix actions | Conservative safe transformations |
| Local AI | Optional Ollama integration |

## Build

```bash
git clone https://github.com/sayan9168/SAYANOX-DEVTOOLS.git
cd SAYANOX-DEVTOOLS

npm install
npm run check
npm run compile
npm run package
```

Install the generated `.vsix` in VS Code / Cursor.
